# Fonction_publique

Site web du Ministère de la Fonction Publique et du Travail — République Islamique de Mauritanie.

Tous les fichiers sont à la racine (aucun sous-dossier) : HTML, `style.css`, `main.js` et les images.

## Pages
- `index.html` — Accueil
- `accueil-ar.html` — Accueil en arabe
- `actualites.html` — Actualités
- `publications.html` — Publications officielles
- `liens-utiles.html` — Liens utiles
- `services.html` — Services en ligne
- `ministre.html` — La Ministre
- `cabinet.html` — Cabinet du Ministre
- `secretariat-general.html` — Secrétariat Général
- `administrations-centrales.html` — Administrations centrales
- `guide-fonctionnaire.html` — Guide du Fonctionnaire
- `travailleurs.html` — Fenêtre sur les travailleurs
- `textes-legislatifs.html` — Textes législatifs
- `reglements-application.html` — Réglements d'application
- `concours-inspecteurs.html` — Concours d'Inspecteurs du Travail
- `plan-depenses.html` — Plan annuel des dépenses

## Déploiement Netlify
Le fichier `netlify.toml` publie la racine du dépôt. Aucune commande de build n'est nécessaire.
